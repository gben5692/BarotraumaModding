# Contributing
To contribute to this repository, You need to have the following.

1. Download the modified barotrauma source code to load the modding framework found here -> [Barotrauma Modified](https://github.com/gben5692/Barotrauma)

2. Compile and build it, You will get the game contents at the bin.

3. Fork this repository .

4. Do some work on it. *No code that harms others! IMPORTANT*

5. Build the repository, It will output a *BarotraumaModdingFramework.dll*

6. Place the outputted *BarotraumaModdingFramework.dll* in the game files found in *Step 2*

7. Run the game and a console will pop up which means it works.

8. Make sure that there is no problems with your code.

9. Then pull a merge request 

10. Hopefully it will be accepted

11. Done
